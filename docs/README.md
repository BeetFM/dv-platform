# Documentation

The documentation is organized by concern:

- [Architecture](architecture/) — system design, adapters, evidence, protocols, semantics, and HDL frontends.
- [Acceptance](acceptance/) — feature and stage acceptance records.
- [Qualification](qualification/) — capability, GA, enterprise, testing, and production-readiness contracts.
- [Operations](operations/) — operator, closure, security, support, and upgrade guidance.
- [Planning](planning/) — implementation and missing-work plans.
- [Compatibility](compatibility/) — the public compatibility contract and deterministic baseline.
- [Configuration](config/) — installation, configuration, and CLI contracts.
- [Architecture decisions](adr/) — accepted architectural decisions.
- [Evidence](evidence/) — retained qualification evidence.
