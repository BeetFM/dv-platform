# Security policy

Keep API keys in the environment or ignored `.env` files. Do not include credentials, proprietary design inputs, or raw customer logs in issue reports. Report suspected vulnerabilities privately to the repository maintainers.

Network calls require explicit configuration. AI routing policy, entitlement verification, plugin publisher/signature checks, bounded tool execution, input fingerprints, export-root checks, and owner-only audit files protect workflow boundaries. Support bundles contain redacted metadata and log digests rather than log contents.

Production entitlement and evidence keys must use an approved trust policy. Keys generated by qualification scripts are local test keys. Timing closure and a successful fixture signature do not confer sign-off approval.
